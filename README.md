# Personal Finance

A personal budgeting app inspired by the practical workflow of Actual Budget.

## First slice

This first version is a browser-based dashboard prototype with sample accounts, category budgets, spending trends, and transaction entry. It is designed to run on Railway. Data is currently demo data held in the browser; it is not yet server-persisted or multi-device.

## Next steps

Add secure authentication, PostgreSQL-backed accounts and transactions, migrations, backups, and import/export before using real financial data. Bank sync is not included.
